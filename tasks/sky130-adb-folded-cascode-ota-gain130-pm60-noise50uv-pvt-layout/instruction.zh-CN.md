# 130 dB增益增强折叠共源共栅OTA版图

以英文版本为准。

根据 `task/circuit.spice` 中的固定电路生成完整布线的 SKY130 版图。
顶层子电路为 `folded_cascode_ota`，端口顺序为：
`vss iref vdd vinn vinp vout`。
保持电路拓扑、器件模型、连接、尺寸以及网表声明的并联倍数参数。
外部测试源、负载、时钟和明确说明的封装测试元件不属于 DUT 版图。

版图须通过已安装 SKY130 规则集的 DRC 和 LVS，且寄生抽取后的电路须满足
以下电气规格。通过紧凑的布局和布线尽可能提高面积利用率，同时满足工艺与电气要求。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 电气规格

外部从vdd向iref供50 µA。主要求覆盖tt/ss/ff × 1.62/1.80/1.98 V × -40/27/125 °C，共27点；输入及目标输出共模0.9 V，输出负载1 pF。

- DC增益≥130 dB、UGB≥200 MHz、相位裕度≥60°、输出误差≤0.8 mV、功率≤5.4 mW。10 Hz—100 GHz返回比恰有一次向下0 dB交越，此后保持低于单位增益；UGB/PM采用该交越。无交越或后续再交越均不通过。
- 10 Hz—10 MHz单位增益输入折算积分噪声≤50 µVrms。
- 闭环范围在TT/1.80 V/27 °C、SS/1.62 V/-40 °C、SS/1.62 V/125 °C检查；扫0.30—1.50 V、步进10 mV，取每采样点abs(vout-vinp)≤20 mV的最长连续区间，只允许在相邻合格/不合格边界样本间插值。该区间≥0.92 Vpp。
- 建立在TT/1.80 V/27 °C、SS/1.98 V/-40 °C、FF/1.98 V/-40 °C检查。命令0.85→0.95→0.85 V，线性边沿1 ns。每方向采用最后进入定义：进入后，观察窗所有剩余样本均在命令端点±0.7 mV内。最坏方向建立≤10 ns；最后5 ns平均误差≤0.7 mV且≤0.1 V阶跃的0.7%。

不评失配、Monte Carlo、CMRR或PSRR。

## 环境

在工作区执行 `source ./eda_env.sh`。原生 EDA 命令见 `GUIDE.zh-CN.md`，
已安装的 SKY130 器件接口见 `DEVICE_API.zh-CN.md`。
你可以自行编写版图、检查和仿真脚本。

原生仿真示例与运行命令见 `task/testbench/README.zh-CN.md`。
这些文件提供代表工况；完整要求仍以上述任务说明中的工况为准。

`ALB_MODEL_LIB` 指定本题已验证的 SKY130 模型库；`ALB_NGSPICE_INIT` 给出
对应的 ngspice 初始化设置。前仿和后仿均按 `GUIDE.zh-CN.md` 的方式使用。
用 `.lib` 选择规定的工艺角，用 `.option scale=1e-6` 解释以微米表示的数值尺寸。
保持网表中已确定的物理器件及其尺寸。若提供 `task/lvs_reference.spice`，
它仅以当前 LVS reader 的语法表达相同器件；仿真使用 `task/circuit.spice`
或抽取后的 DUT，不使用 LVS 专用参考。

仅使用已提供文件、已安装软件及本地文档离线工作。不得通过浏览器、Web 工具、
shell 命令、包管理器或脚本访问网络。由评测基础设施管理的 harness 模型 API
连接是唯一允许的网络用途。

## 交付

生成版图后，请及时保存到 `submission/layout.gds`，并在迭代过程中持续更新；即使 DRC、LVS 或后仿尚未全部通过，也请保留当前版本供运行结束后的验收。

- 版图保存为 `submission/layout.gds`，顶层 cell 为 `folded_cascode_ota`。
- 生成版图的源代码放在 `submission/src/` 下。
- 临时文件和诊断输出放在 `work/` 下。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版电气验收只执行公开测试台 `tb_noise.spi`, `tb_op_ac.spi`, `tb_range.spi`, `tb_settling.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况。后仿使用同一测试条件，将 DUT 换为抽取网表。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
