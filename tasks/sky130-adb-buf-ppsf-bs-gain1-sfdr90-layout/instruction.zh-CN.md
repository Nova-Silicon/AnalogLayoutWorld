# 差分推挽源随缓冲器版图

英文版本为准。

为 `task/circuit.spice` 中的固定电路生成完成布线的 SKY130 版图。
顶层子电路为 `buf_ppsf_bs`，端口顺序是
`IREF VCM VDD VIN VIP VON VOP VSS`。
保持拓扑、连接、器件型号、尺寸和并联倍数不变。
保留每个 MOS 的体端连接，包括各个独立 NMOS 体端。
外部电源、偏置、共模基准及输出负载属于测试条件，不属于 DUT 版图。

8 个内部电阻采用 `sky130_fd_pr__res_generic_po`，
每个为 `w=0.33 l=5684.65`，单位为微米。
8 个内部电容采用 `sky130_fd_pr__cap_mim_m3_1`，
每个为 `w=49.85 l=49.85`，单位为微米。这些真实器件型号和尺寸固定。
DRC 使用已安装的 KLayout 规则；LVS 使用 `GUIDE.zh-CN.md` 中的
**Magic + Netgen 原生流程**，直接与 `task/circuit.spice` 比较。

版图必须通过 DRC、LVS，并在寄生抽取后满足以下电气规格。
在保证工艺及电气要求的前提下，紧凑放置和布线，尽可能提高面积利用率。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 电气规格

电气条件和限制沿用来源 benchmark 的规格。

- 检查 SKY130 的 `tt`、`ff`、`ss`、`fs`、`sf` 五个工艺角，
  电源 1.80 V、温度 27 C。向 `IREF` 注入 20 uA，`VCM` 保持 0.90 V；
  `VIN`、`VIP` 施加差分峰值为 0.8 V 的正弦输入，每个输出接 1 pF 到地。
- 每个工艺角，在 40 MHz、差分 AC 峰值 0.8 V 驱动下，
  差分输入电流幅值 `|I(VIP)-I(VIN)|` 必须**小于 20 uA**。
  测量缺失或非有限值均不通过。
- 每个工艺角，1 MHz 至 40 MHz 的所有 AC 采样点上，差分增益幅值
  必须**大于 0.99 V/V**。
- 每个工艺角，大信号 SFDR 必须在 **1 MHz 大于 90 dB、
  11 MHz 大于 80 dB、41 MHz 大于 70 dB**。
  这 15 个条件下的基波差分增益还必须均**大于 0.95 V/V**。
  使用 `task/testbench/README.zh-CN.md` 中的全奈奎斯特带宽矩形窗频谱定义。
- 每个工艺角，外部提供的总直流功耗必须**小于 1 mW**。
  按 `VDD`、`VCM`、`VIN`、`VIP` 各端口直流功率绝对值之和计算。

所有条件都必须通过。本题指定矩阵不包含电源电压变化、
27 C 以外的温度或统计失配。

## 环境

先执行 `source ./eda_env.sh`。`GUIDE.zh-CN.md` 说明原生检查、抽取、
仿真命令；`DEVICE_API.zh-CN.md` 说明已安装的器件接口。
可以自行编写版图及检查脚本。原生测试台和精确测量定义位于
`task/testbench/README.zh-CN.md`。

使用 `ALB_MODEL_LIB` 选择的原 continuous 模型库，以及 `ALB_NGSPICE_INIT`
中的已验证初始化。前仿和后仿保持相同选择。
器件数字尺寸使用这些模型规定的微米单位，保留所给测试台的缩放和初始化。

仅使用已提供文件、已安装软件和本地文档，离线完成任务。
不得通过浏览器、网络工具、shell、包管理器或脚本联网。
唯一允许的网络使用是评测基础设施管理的 harness 模型 API 连接。

## 交付

生成版图后，请及时保存到 `submission/layout.gds`，并在迭代过程中持续更新；即使 DRC、LVS 或后仿尚未全部通过，也请保留当前版本供运行结束后的验收。

- 将 GDS 保存为 `submission/layout.gds`，顶层单元为 `buf_ppsf_bs`。
- 版图生成代码保存到 `submission/src/`。
- 临时文件及诊断输出保存到 `work/`。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版电气验收只执行公开测试台 `tb_ac_power.spi`, `tb_sfdr.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况。后仿使用同一测试条件，将 DUT 换为抽取网表。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
