# 50 µA 匹配 UP/DN 电流的 PLL 电荷泵版图

以英文版本为准。

根据 `task/circuit.spice` 中的固定电路生成完整布线的 SKY130 版图。
顶层子电路为 `pll_charge_pump`，端口顺序为：
`vss iref up dn vdd vout`。
保持电路拓扑、器件模型、连接、尺寸以及网表声明的并联倍数参数。
外部测试源、负载、时钟和明确说明的封装测试元件不属于 DUT 版图。

版图须通过已安装 SKY130 规则集的 DRC 和 LVS，且寄生抽取后的电路须满足
以下电气规格。通过紧凑的布局和布线尽可能提高面积利用率，同时满足工艺与电气要求。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 电气规格

直流电流、输出合规范围、非激活状态和匹配要求覆盖 `tt/ss/ff`，1.62/1.80/1.98 V，-40/27/125 °C 的全部 27 个 PVT 组合。外部提供 25 µA 参考；`up` 和 `dn` 分别控制标称 +50 µA、-50 µA 输出电流。

- 输出 0.45—1.15 V 范围内，每支路相对标称的偏差≤5%，平坦度变化≤1%；UP/DN 失配≤2%。
- 两个控制均为低时，在 0.30—1.35 V 输出范围内泄漏≤1 nA；两个控制均为高时，在 0.45—1.15 V 范围内净输出电流≤1 µA。
- 在 `tt/1.80 V/27 °C`，使用 SKY130 `tt_mm`，对完整、预先规定且不按结果筛选的连续种子区间 `31001`—`31020` 检查局部 UP/DN 匹配。每个种子、每个 `vout=0.45/0.90/1.15 V` 点，UP 和 DN 电流均须在 50 µA 的 ±5% 内；以 50 µA 为基准的逐点失配≤2%。这是确定性失配回归集，不是 Monte Carlo 良率结论。
- 10 ns 控制脉冲的送出电荷，相对同 PVT、`vout=0.9 V` 的本支路 DC 电流，误差 `abs(Q_10/(I_DC,0.9V*10 ns)-1)≤5%`。1 ns 脉冲相对本支路实测 10 ns 电荷的十分之一，误差 `abs(Q_1/(Q_10/10)-1)≤25%`。同时重叠时净电荷≤20 fC。
- 开启至 90% 的时间≤0.5 ns，关闭至 5% 的时间≤0.05 ns，平均供电功耗≤500 µW。

脉冲、切换、重叠、功耗在 `tt/1.80 V/27 °C`、`ss/1.62 V/125 °C`、`ff/1.98 V/-40 °C` 检查。瞬态脉冲测试固定 `vout=0.9 V`，UP、DN 的上升和下降时间均为 200 ps。

## 环境

在工作区执行 `source ./eda_env.sh`。原生 EDA 命令见 `GUIDE.zh-CN.md`，
已安装的 SKY130 器件接口见 `DEVICE_API.zh-CN.md`。
你可以自行编写版图、检查和仿真脚本。

原生仿真示例与运行命令见 `task/testbench/README.zh-CN.md`。
这些文件提供代表工况；完整要求仍以上述任务说明中的工况为准。

`ALB_MODEL_LIB` 指定本题已验证的 SKY130 模型库；`ALB_NGSPICE_INIT` 给出
对应的 ngspice 初始化设置。前仿和后仿均按 `GUIDE.zh-CN.md` 的方式使用。
用 `.lib` 选择规定的工艺角，用 `.option scale=1e-6` 解释以微米表示的数值尺寸。
保持网表中已确定的物理器件及其尺寸。若提供 `task/lvs_reference.spice`，
它仅以当前 LVS reader 的语法表达相同器件；仿真使用 `task/circuit.spice`
或抽取后的 DUT，不使用 LVS 专用参考。

仅使用已提供文件、已安装软件及本地文档离线工作。不得通过浏览器、Web 工具、
shell 命令、包管理器或脚本访问网络。由评测基础设施管理的 harness 模型 API
连接是唯一允许的网络用途。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版后仿计分只执行公开测试台 `tb_dc.spi`, `tb_pulse.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况；将 DUT 换为抽取网表，保留相同测试条件。
失配／蒙特卡洛测试台 `tb_mm.spi` 保留用于参考电路资格检查，按原始完整固定种子集合及其统计或逐样本判据运行；这些资格结果单独记录，不参与提取后 DUT 的后仿计分或通过比例。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
