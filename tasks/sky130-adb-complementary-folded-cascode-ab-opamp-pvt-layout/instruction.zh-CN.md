# 互补轨到轨 Class-AB 折叠共源共栅运放版图

以英文版本为准。

根据 `task/circuit.spice` 中的固定电路生成完整布线的 SKY130 版图。
顶层子电路为 `complementary_folded_cascode_ab_opamp`，端口顺序为：
`vss iref vdd vinn vinp vout`。
保持电路拓扑、器件模型、连接、尺寸以及网表声明的并联倍数参数。
外部测试源、负载、时钟和明确说明的封装测试元件不属于 DUT 版图。

版图须通过已安装 SKY130 规则集的 DRC 和 LVS，且寄生抽取后的电路须满足
以下电气规格。通过紧凑的布局和布线尽可能提高面积利用率，同时满足工艺与电气要求。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 电气规格

使用 1.8 V SKY130 核心器件，外部参考电流 20 µA。五角 tt/ff/ss/fs/sf 各覆盖 1.62 V/-40 °C、1.62 V/125 °C、1.80 V/27 °C、1.98 V/-40 °C、1.98 V/125 °C，共25点，是标称加电源/温度边界覆盖，不是45点完整组合。

电路具有互补 NMOS/PMOS 输入路径、折叠共源共栅电流求和级、浮动电流源 Class-AB 输出级及串联 RC 米勒补偿。顶层 complementary_folded_cascode_ab_opamp 的端口为 vss iref vdd vinn vinp vout，固定网表决定其具体实现；负载和激励在 DUT 外。

- AC 负载4 pF，用仅DC有效的电平偏移反馈使输出保持 VDD/2，同时独立扫输入共模，并用1 TΩ回到VDD/2防输出悬浮。每个PVT检查 VCM=0.1 V、0.2 V、VDD/2、VDD-0.2 V、VDD-0.1 V。10 Hz 开环增益在中间三点≥90 dB，近轨两点≥80 dB。
- 全部共模点 UGB≥1 MHz；中间三点相位裕度≥60°，近轨两点≥55°；全PVT/共模矩阵 UGB最大/最小≤2.0。缺增益、缺单位交越、相位非有限或矩阵缺项均不通过。AC输出不偏置到轨；输出摆幅/大信号行为由闭环测试另查。
- 接10 kΩ到VDD/2，单位增益跟踪误差在0.1—VDD-0.1 V范围≤20 mV，在0.2—VDD-0.2 V范围≤5 mV。测得输入共模跨度≥1.5 V，并到达距两轨各0.1 V以内。
- 包含20 µA参考支路的静态供电功率≤1.5 mW；每个PVT检查中点AC工作点及0—VDD闭环输入扫描的最大功率。
- 单位增益0.2 V↔VDD-0.2 V阶跃驱动4 pF并联10 kΩ到VDD/2，两方向压摆率≥2 V/µs；每个2 µs命令平台最后100 ns，输出在命令值±5 mV内。
- CMRR、PSRR、失真使用固定绝对共模0.9 V，覆盖TT/1.80 V/27 °C、SS/1.62 V/125 °C、FF/1.98 V/-40 °C。CMRR在1 kHz≥70 dB、1 MHz≥55 dB；PSRR在10 Hz≥45 dB、1 MHz≥10 dB。
- 全25点在VCM=VDD/2、4 pF并联10 kΩ负载下，10 Hz—1 MHz单位增益输入折算积分噪声≤70 µVrms。上述三个代表点的单位增益1 kHz、峰值0.4 V、中心0.9 V正弦，傅里叶THD≤0.01%，有界失真残差≤命令幅值0.5%。TT/1.80 V/27 °C、VCM=VDD/2的三个固定tt_mm种子，各自闭环失调≤5 mV；这是回归覆盖而非统计良率。

跟踪、阶跃、噪声、失真、失调使用4 pF并联10 kΩ到VDD/2。CMRR/PSRR使用其差分参考实例、4 pF负载和100 MΩ DC回路。任何缺失、非有限或不完整的PVT测量均不能算通过。

## 环境

在工作区执行 `source ./eda_env.sh`。原生 EDA 命令见 `GUIDE.zh-CN.md`，
已安装的 SKY130 器件接口见 `DEVICE_API.zh-CN.md`。
你可以自行编写版图、检查和仿真脚本。

原生仿真示例与运行命令见 `task/testbench/README.zh-CN.md`。
这些文件提供代表工况；完整要求仍以上述任务说明中的工况为准。

`ALB_MODEL_LIB` 指定本题已验证的 SKY130 模型库；`ALB_NGSPICE_INIT` 给出
对应的 ngspice 初始化设置。前仿和后仿均按 `GUIDE.zh-CN.md` 的方式使用。
用 `.lib` 选择规定的工艺角，用 `.option scale=1e-6` 解释以微米表示的数值尺寸。
保持网表中已确定的物理器件及其尺寸。若提供 `task/lvs_reference.spice`，
它仅以当前 LVS reader 的语法表达相同器件；仿真使用 `task/circuit.spice`
或抽取后的 DUT，不使用 LVS 专用参考。

仅使用已提供文件、已安装软件及本地文档离线工作。不得通过浏览器、Web 工具、
shell 命令、包管理器或脚本访问网络。由评测基础设施管理的 harness 模型 API
连接是唯一允许的网络用途。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版后仿计分只执行公开测试台 `tb_ac.spi`, `tb_cmrr.spi`, `tb_noise.spi`, `tb_psrr.spi`, `tb_step.spi`, `tb_thd.spi`, `tb_track.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况；将 DUT 换为抽取网表，保留相同测试条件。
失配／蒙特卡洛测试台 `tb_offset.spi` 保留用于参考电路资格检查，按原始完整固定种子集合及其统计或逐样本判据运行；这些资格结果单独记录，不参与提取后 DUT 的后仿计分或通过比例。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
