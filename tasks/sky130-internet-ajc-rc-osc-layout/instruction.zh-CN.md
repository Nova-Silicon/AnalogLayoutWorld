# 可使能 RC 振荡器版图

英文版本为准。

这是从上电复位电路中独立出来的松弛振荡器，包含使能、禁用和重新启动功能。本任务不包含完整 POR 或数字计数器。

为 `task/circuit.spice` 中的固定电路生成完整布线的 SKY130 版图。顶层子电路为 `rc_osc`，端口顺序为：
`dvdd out ena dvss`。
保持拓扑、器件型号、连接和固定尺寸。

保留源网表中的全部 dummy 晶体管。内部十段电阻均为 `sky130_fd_pr__res_xhigh_po_1p41`，每段 L=111 µm，第三端连接 `dvss`。`XC1` 是 W=L=30 µm、六个并联单元（`m=6`）的 `sky130_fd_pr__cap_mim_m3_2`。电源、使能激励和 50 fF 输出负载均为外部测试条件。

LVS 使用 `task/lvs_reference.spice`，它只为安装的 reader 调整实例名前缀及 MIM 面积/周长表示，器件连接和物理尺寸不变。仿真使用 `task/circuit.spice` 或从 GDS 抽取的 DUT，不要使用 LVS 专用参考。

版图必须使用安装的 SKY130 decks 通过 DRC/LVS，并在寄生抽取后满足以下电气规格。在不牺牲工艺与电气要求的前提下，紧凑放置和布线，尽可能提高面积利用率。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 规格

- 在 VDD=1.8 V、输出负载 50 fF 下，覆盖工艺 `tt`/`ss`/`ff` 与温度 -40/27/125 °C 的全部九种组合。
- `ena` 初始为低，在 100–100.01 µs 从 0 升至 1.8 V，在 3–3.00001 ms 降为低，在 4–4.00001 ms 再次升高；仿真至 6 ms。
- 输出边沿以 0.9 V 为阈值。在 1–2.5 ms 内，频率按上升沿周期中位数的倒数计算，要求 10–70 kHz；周期峰峰值除以平均周期不超过 0.03；各周期占空比均为 0.20–0.60。
- 初次使能和重新使能后，从使能上升沿结束时刻起，首个输出上升沿均须在 1 ms 内出现。
- 1–2.5 ms 平均供电功耗不超过 150 µW。3.3–3.8 ms 禁用窗口内，平均供电电流不超过 100 nA，输出最大值不超过 0.18 V。
- 本规格只覆盖上述九个点，不额外要求更宽供电范围、独立 R/C 角点或失配。

## 环境

在工作区执行 `source ./eda_env.sh`。原生 EDA 命令见 `GUIDE.zh-CN.md`，
已安装的 SKY130 器件接口见 `DEVICE_API.zh-CN.md`。
你可以自行编写版图、检查和仿真脚本。

原生仿真示例与运行命令见 `task/testbench/README.zh-CN.md`。
这些文件提供代表工况；完整要求仍以上述任务说明中的工况为准。

`ALB_MODEL_LIB` 指定本题已验证的 SKY130 模型库；`ALB_NGSPICE_INIT` 给出
对应的 ngspice 初始化设置。前仿和后仿均按 `GUIDE.zh-CN.md` 的方式使用。
用 `.lib` 选择规定的工艺角，用 `.option scale=1e-6` 解释以微米表示的数值尺寸。
保持网表中已确定的物理器件及其尺寸。若提供 `task/lvs_reference.spice`，
它仅以当前 LVS reader 的语法表达相同器件；仿真使用 `task/circuit.spice`
或抽取后的 DUT，不使用 LVS 专用参考。

仅使用已提供文件、已安装软件及本地文档离线工作。不得通过浏览器、Web 工具、
shell 命令、包管理器或脚本访问网络。由评测基础设施管理的 harness 模型 API
连接是唯一允许的网络用途。

## 交付

生成版图后，请及时保存到 `submission/layout.gds`，并在迭代过程中持续更新；即使 DRC、LVS 或后仿尚未全部通过，也请保留当前版本供运行结束后的验收。

- 将版图保存为 `submission/layout.gds`，顶层 cell 为 `rc_osc`。
- 将版图生成代码保存在 `submission/src/`。
- 临时文件和诊断输出放在 `work/`。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版电气验收只执行公开测试台 `tb_rc_osc.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况。后仿使用同一测试条件，将 DUT 换为抽取网表。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
