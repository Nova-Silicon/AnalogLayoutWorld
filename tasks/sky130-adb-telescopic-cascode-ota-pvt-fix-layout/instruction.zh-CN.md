# 套筒式共源共栅全差分 OTA 版图

以英文版本为准。

根据 `task/circuit.spice` 中的固定电路生成完整布线的 SKY130 版图。
顶层子电路为 `telescopic_cascode_ota`，端口顺序为：
`vss iref vdd vinn vinp vocm voutn voutp`。
保持电路拓扑、器件模型、连接、尺寸以及网表声明的并联倍数参数。
外部测试源、负载、时钟和明确说明的封装测试元件不属于 DUT 版图。

版图须通过已安装 SKY130 规则集的 DRC 和 LVS，且寄生抽取后的电路须满足
以下电气规格。通过紧凑的布局和布线尽可能提高面积利用率，同时满足工艺与电气要求。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 电气规格

接口为 `.subckt telescopic_cascode_ota vss iref vdd vinn vinp vocm voutn voutp`。外部向 `iref` 强制提供 50 µA，输入共模 0.9 V；除特别说明外，输出共模目标 0.9 V。每个输出负载 2 pF。

PVT 要求覆盖 `tt`、`ff`、`ss`，1.62、1.80、1.98 V，-40、27、125 °C 的全部 27 个唯一组合。1 Hz—10 GHz AC 扫描中必须恰有一次向下穿越 0 dB；第一次交越后始终低于单位增益。UGB 和相位裕度在该第一次向下交越测量。

| 测量 | 要求 |
|---|---:|
| 1 Hz 扫描点的 DC 差分增益 | 大于 60 dB |
| 单位增益带宽 | 大于 50 MHz |
| 第一次向下 0 dB 交越的相位裕度 | 大于 60° |
| 输出共模误差 | 小于 5 mV |
| 总 VDD 功耗 | 非负且小于 1 mW |

以下闭环测量使用 `tt/1.80 V/27 °C`：

- **差分范围：**理想外部单位反馈环路将差分指令从 -0.45 V 扫至 +0.45 V，步进 5 mV，共 181 点，完整覆盖 0.90 Vpp。每点差分跟踪误差和输出共模误差均≤5 mV。
- **差分稳定时间：**同一环路在 20 ns 开始用 1 ns 线性边沿将指令从 -50 mV 变到 +50 mV。从指令首次到达 +50 mV 开始，直到某输出采样点后全部后续样本都保持在 100 mV 阶跃的 1% 内；该最后进入时间小于 10 ns。最后 10 ns 的差分输出平均误差≤0.1 mV，且≤阶跃的 1%。
- **共模恢复：**差分输入为零，`vocm` 在 20 ns 开始用 1 ns 线性边沿从 0.85 V 变到 0.95 V。从指令首次达到 0.95 V 开始，直到某输出共模采样点后全部后续样本保持在 5 mV 内；该最后进入时间小于 40 ns。最后 20 ns 的平均误差≤5 mV。

固定 50 µA 参考及声明的 27 个 `tt/ff/ss` 点是全部电气工况覆盖。不包括 `fs/sf`、参考电流变化、0.9 V 之外的输入共模范围、CMRR、PSRR、噪声、失配和 Monte Carlo。零差分指令下的不平衡由差分范围测试的 0 V 点约束，不是额外的 PVT 指标。

## 环境

在工作区执行 `source ./eda_env.sh`。原生 EDA 命令见 `GUIDE.zh-CN.md`，
已安装的 SKY130 器件接口见 `DEVICE_API.zh-CN.md`。
你可以自行编写版图、检查和仿真脚本。

原生仿真示例与运行命令见 `task/testbench/README.zh-CN.md`。
这些文件提供代表工况；完整要求仍以上述任务说明中的工况为准。

`ALB_MODEL_LIB` 指定本题已验证的 SKY130 模型库；`ALB_NGSPICE_INIT` 给出
对应的 ngspice 初始化设置。前仿和后仿均按 `GUIDE.zh-CN.md` 的方式使用。
用 `.lib` 选择规定的工艺角，用 `.option scale=1e-6` 解释以微米表示的数值尺寸。
保持网表中已确定的物理器件及其尺寸。若提供 `task/lvs_reference.spice`，
它仅以当前 LVS reader 的语法表达相同器件；仿真使用 `task/circuit.spice`
或抽取后的 DUT，不使用 LVS 专用参考。

仅使用已提供文件、已安装软件及本地文档离线工作。不得通过浏览器、Web 工具、
shell 命令、包管理器或脚本访问网络。由评测基础设施管理的 harness 模型 API
连接是唯一允许的网络用途。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版电气验收只执行公开测试台 `tb_cm_recovery.spi`, `tb_pvt.spi`, `tb_settling.spi`, `tb_swing.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况。后仿使用同一测试条件，将 DUT 换为抽取网表。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
