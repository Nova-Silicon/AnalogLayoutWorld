# 10:1容性负载范围两级OTA版图

本页为中文译文，以英文版本为准。

为 `task/circuit.spice` 中的固定电路完成包含布线的SKY130版图。
顶层子电路为 `ahuja_ota`，端口顺序为：
`vss iref vdd vinp vinn vout`。
保持电路拓扑、器件型号、连接与尺寸。
偏置源、输入信号、输出负载和测量用反馈网络属于外部测试条件，不属于DUT版图。

内部电阻采用 `sky130_fd_pr__res_high_po_1p41`，第三端连接 `vss`；
内部电容采用 `sky130_fd_pr__cap_mim_m3_1`。网表中的型号和尺寸均固定。
LVS 使用 `task/lvs_reference.spice`，其中 MIM 以固定 reader 所需的面积/周长
语法表示相同的物理尺寸。仿真使用 `task/circuit.spice` 或抽取后的 DUT，
不使用仅供 LVS 的参考网表。

版图必须通过环境内SKY130规则的DRC和LVS检查，并在寄生抽取后满足以下电气规格。
在不影响工艺和电气要求的前提下，紧凑放置器件并布线，尽可能提高面积利用率。

## 执行预算与版图目标

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，
用于版图生成、调试和自查。请在此预算内自行安排工作，并在到期前保存要求的
交付文件。随后进行的正式验收不占用这 3 小时 Agent 预算。

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的
前提下，通过紧凑布局布线尽可能减小版图总面积、提高面积利用率，同时满足
工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 电气规格

- 测试台向 `iref` 提供50 µA电流。输出目标电压和输入共模电压均为0.9 V。
- 20 pF与200 pF负载的AC测试、DC跟随测试、200 pF负载的跟随瞬态测试，分别覆盖 `tt`/`ff`/`ss`/`fs`/`sf`、1.62/1.80/1.98 V、−40/27/125°C的全部45种组合。另以63 pF负载在1.80 V、27°C下检查所有工艺角的AC稳定性。
- AC测试在 `vinp` 施加1 V小信号，并通过500 MΩ/50 mF直流伺服网络将 `vout` 反馈至 `vinn`；该网络在测量的AC频段内近似开环。20 pF负载下，10 Hz增益至少为58 dB，首次下降穿越0 dB的频率至少为6.5 MHz。在每个规定的AC工况下，该交越处的相位裕度至少为60°，且环路增益在300 MHz之前不得重新上升至0 dB以上。
- 在20 pF负载的DC跟随条件下，输出相对0.9 V的绝对偏差不超过6 mV，供电功耗不超过2 mW。
- 在200 pF负载和直接单位反馈（`vinn = vout`）条件下，`vinp` 施加0.9 V→1.2 V→0.9 V脉冲，上下沿均为10 ns。从输入各边沿完成变化量1%的交越时刻开始计时，`vout` 必须在2 µs内进入并保持在已知0.3 V阶跃目标的±6 mV范围内。每个命令电平结束时的误差也不得超过6 mV。

## 环境

在工作区执行 `source ./eda_env.sh`。原生 EDA 命令见 `GUIDE.zh-CN.md`，
已安装的 SKY130 器件接口见 `DEVICE_API.zh-CN.md`。
你可以自行编写版图、检查和仿真脚本。

原生仿真示例与运行命令见 `task/testbench/README.zh-CN.md`。
这些文件提供代表工况；完整要求仍以上述任务说明中的工况为准。

`ALB_MODEL_LIB` 指定本题已验证的 SKY130 模型库；`ALB_NGSPICE_INIT` 给出
对应的 ngspice 初始化设置。前仿和后仿均按 `GUIDE.zh-CN.md` 的方式使用。
用 `.lib` 选择规定的工艺角，用 `.option scale=1e-6` 解释以微米表示的数值尺寸。
保持网表中已确定的物理器件及其尺寸。若提供 `task/lvs_reference.spice`，
它仅以当前 LVS reader 的语法表达相同器件；仿真使用 `task/circuit.spice`
或抽取后的 DUT，不使用 LVS 专用参考。

仅使用已提供文件、已安装软件及本地文档离线工作。不得通过浏览器、Web 工具、
shell 命令、包管理器或脚本访问网络。由评测基础设施管理的 harness 模型 API
连接是唯一允许的网络用途。

## 本版验收覆盖范围

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版电气验收只执行公开测试台 `tb_guard.spi`, `tb_heavy.spi`, `tb_light.spi`, `tb_step.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况。后仿使用同一测试条件，将 DUT 换为抽取网表。
只对这些测试实际覆盖的指标计分；未覆盖的全范围性质和多样本统计标为未评测，不能把有限测试通过解释为完整 SPEC 通过。DRC、LVS 和提交要求不变。
