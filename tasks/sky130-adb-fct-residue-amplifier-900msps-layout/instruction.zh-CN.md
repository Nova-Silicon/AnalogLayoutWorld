# 900 MS/s 浮动电荷转移余量放大器版图

以英文版本为准，本文件为中文译文。

根据 `task/circuit.spice` 的固定电路生成完整布线的 SKY130 版图。
顶层子电路为 `test_fct`，端口顺序为：
`cinn cinp coutn coutp ib sam transfer vcm vddana vdddig vssana vssdig`。
保持拓扑、器件型号、连接、MOS 尺寸及倍数、电容尺寸不变。
内部 14 个电容均为固定的 `sky130_fd_pr__cap_mim_m3_1` 器件。
时钟缓冲器和反相器子电路属于 DUT。

外部飞跨电容、采样/转移开关、输出预充电、跟踪保持开关、电源、
偏置/参考源、激励和输出负载属于测试台，不属于版图。
`vssana` 与 `vssdig` 是 DUT 内不同的网络，仅由测试台在外部连接。
保持全部独立 NMOS、PMOS 体端连接。

版图应通过安装的 SKY130 KLayout DRC，以及 Magic 抽取加 Netgen LVS。
LVS 直接与 `task/circuit.spice` 比较。
寄生抽取后须满足以下规格。应紧凑布局布线，尽可能提高面积利用率，
同时满足工艺和电气要求。

Agent 的执行时间上限为 **3 小时（10800 秒，按实际经过时间计）**，

通过 DRC、LVS 和本版验收覆盖的后仿测试是基本要求。在保持固定电路约束的

工艺与电气要求。请按电路需要考虑器件匹配与对称、敏感网络的寄生与耦合、
供电和地线布线、体端及阱接触与隔离。

## 规格

FCT 是采样电荷转移电路，不是连续时间电压放大器。
固定测试台先执行一次 1 ns 启动预充电；随后每个 `sam` 阶段，
相对于 `vcm` 把输入采样到两个 400 fF 飞跨电容，并将测试台输出
预充到 `vocm`。`transfer` 阶段把飞跨电容接至 `vcm` 和 DUT 的
`cinn/cinp`；`sample_out` 阶段将 `coutn/coutp` 跟踪到 `voutn/voutp`，
然后释放并保持输出。

- 工艺角为 `tt`、`ss`、`ff`、`fs`、`sf`，电源 1.8 V，温度 27 C。
  沿用原始确定性全局工艺角规格，不要求额外电源/温度扫描、失配或
  无源器件工艺扫描。
- 两个 DUT 电源端在外部共用 1.8 V 源，两个地端在外部共地。
  参考电流 50 µA；输入共模 1.0 V；0.9 V 输出预充参考不持续
  调节输出共模。测试台每个输出负载 50 fF。
- 采样率 900 MS/s。保持提供的原生测试台中的时钟相位和边沿时序。
- 每个工艺角均测试两种差分正弦峰值：10 mV，FFT 第 5 频点
  （140.625 MHz）；20 mV，第 3 频点（84.375 MHz）。
  完整验证共 10 次瞬态分析。
- 每次先运行 64 个启动周期，再测量恰好 32 个相干采样值。
  在每个计分周期边界后的 0.78 ns（跟踪中）和 0.88 ns（释放后）
  采样。增益、SFDR、共模和范围使用 0.88 ns 的保持输出。

两种输入幅度、全部五个工艺角均须满足：

| 指标 | 要求 |
|---|---|
| 采样差分增益 | 5.5–6.5 V/V |
| 采样 SFDR | ≥60 dB |
| 采样输出共模均值 | 0.3–1.2 V |
| 每个采样输出电压 | 0.2–1.6 V |
| 归一化跟踪到保持变化 | ≤0.015（1.5%） |
| 全部供能 DUT 端口交付的平均总功耗 | 0–5 mW |

仅在增益/SFDR 的 FFT 前去掉差分输出直流分量。
增益为 32 点差分输出基波峰值除以指定输入峰值。
SFDR 为基波与其余非直流频点中最大分量的比值，包含奈奎斯特频点。
令 `d_track[k]`、`d_held[k]` 分别为 0.78 ns、0.88 ns 的差分输出，
保持变化定义为 `sqrt(sum((d_track-d_held)^2) / sum(d_held^2))`。
它测量跟踪到保持的输出变化，不是相对于某个指定目标的绝对建立误差。

平均功耗在第 64 至第 96 周期计算，汇总共用 DUT VDD 源、
独立 DUT `vcm`、`sam`、`transfer` 电压源和 50 µA `ib` 电流源
交付的功率。VDD 项包括两个 DUT 电源端。
测试台自身开关、参考、预充/保持通路和激励使用独立源，不计入 DUT。
所给测试台已保持这一统计口径。两个 TT 幅度及其余八个工况都须通过。

## 环境

`DEVICE_API.md` 的 SKY130 器件接口，可自行编写脚本。

数值型尺寸按该模型的微米参数约定填写，所选模型库已经在
`models_global.spice` 中设置 `.option scale=1.0u`。

仅使用提供的文件、已安装软件和本地文档离线工作。
不得通过浏览器、网页工具、shell、包管理器或脚本联网。
评测基础设施管理的模型 API 连接是唯一允许的网络使用。

题面中的完整 SPEC（包括完整 PVT、负载范围及统计要求）仍是设计目标，没有删减。
本版电气验收只执行公开测试台 `tb_10mv_tt.spi`, `tb_20mv_tt.spi` 中已经写明的工况、激励与分析，不再自动展开其余工况。后仿使用同一测试条件，将 DUT 换为抽取网表。
