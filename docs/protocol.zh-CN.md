# 任务与评分协议

[English](protocol.md) | **简体中文** · [文档索引](README.zh-CN.md)

本版包含 40 道固定网表任务，稳定任务 ID 和显示编号 1–40 见
`configs/paper-v1/tasks.json`。每道题分别规定电路、公开测试台、验收项目及提交要求。

## 执行

每次尝试有 10,800 秒用于生成版图、调试和自检。Agent 结束后进行正式验收：
外层时限为 3,600 秒，内部预算为 3,300 秒，为保存部分证据和收集报告预留时间。
验收器使用实际分配的 CPU 数量，并据此限制并行仿真。

每个并行任务默认分配 6 CPU、32 GiB 内存。正式运行命令采用每题三次独立尝试；
首次配置诊断可只运行一次。

镜像包含两组固定的 SKY130 模型：9 题使用 ngspice/binned 模型，31 题使用
combined/continuous 模型。逐题运行配置保留这些选择。

## 输入与独立验收

Agent 只接收任务公开环境和指令。正式提交包括 `submission/layout.gds`
和 `submission/src/` 下的 Python 生成源码；README 可选。
验收器检查 GDS，不执行提交源码，也不把 Agent 自报的结果当作正式证据。

Agent 结束后，Harbor 只将任务声明的提交文件传入新建的验收容器。
验收器使用独立的任务输入和可信测试，检查输入及工具清单，并禁用网络。
Agent 对工作区的修改不会改变可信参考电路或评分配置。

## 评分

总分由六个非负项目相加：

| 项目 | 权重 |
|---|---:|
| 产出 GDS | 0.10 |
| LVS | 0.10 |
| DRC | 0.10 |
| 有效面积 | 0.20 |
| 工程质量 | 0.10 |
| 版图后仿 | 0.40 |

LVS 未通过时不计后续工程加分。DRC 未通过不会自动阻止所有后续项目计分。
长宽比、最低有效面积率及固定的形态检查共同决定相应加分资格；
逐题数值见版本化参数文件。面积指数为 2，归一化面积得分上限为 1。

有效面积由抽取后能与参考电路对应的器件计算，不是 PCell 外框面积之和，
也不只是 W×L。MOS 包括沟道和源漏扩散面积；电阻、电容使用相应器件面积，
BJT 使用识别区域。不同器件可能重叠，因此原始有效面积率可以大于 1。

工程质量采用程序计算的匹配、关键线和电源指标，不使用 LLM 裁判。
三项权重为 0.40/0.45/0.15，对应独立饱和阈值为 0.80/0.80/0.90。
不适用项移出分母；适用但缺少证据的项保留权重、按零计入。
缺少必须的耦合证据时，不计对应质量分。

后仿分取成功抽取后、固定必测项目中已完成且通过的比例。未完成项目保留在分母中。
已经验证的通过项在内部超时后仍可获得相应部分分，未知结果不会被当成通过。
报告会区分基于部分证据的下界分数与完整测量得分。

通过所选测试台不代表覆盖上游规格的所有工况。
实际测量范围和未覆盖条件会在验收输出中说明。

固定参数源为 `src/analoglayoutworld/data/paper-v1.json`。

## 报告

结合 `evaluation/metrics.json` 和各阶段报告阅读结果：
`score_valid` 表示计分证据可用，`evaluation_error` 标识验收器或证据错误，
`pipeline_completed` 表示流程已结束，`design_passed` 表示设计是否通过。
`score_is_lower_bound` 表示仍有项目待完成、当前只有已验证部分分，不等于设计通过。

Harbor 的产物目录见[结果说明](running.zh-CN.md#results)。
独立 `alw verify` 的命令、报告路径和退出码见[已有 GDS 的验收](running.zh-CN.md#existing-gds)。
